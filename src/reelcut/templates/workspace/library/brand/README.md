# Brand

- `logo.png`: your logo, used on titles (the path is `[brand] logo` in `reelcut.toml`).
- `fonts/`: font files for captions and titles. Set `[captions] font` to a file here, or leave it as `TikTok Sans` (the default; `Inter` is also bundled).

Brand colours live in `reelcut.toml` under `[brand]` and `[captions]`.
