# The EDL references transcript IDs, not timestamps

Segments and event anchors in `edl.json` name words (`c1.w52`), utterances (`c1.s4`) or segments, never seconds. The resolver turns them into frame-accurate times with the same padding, pause-tightening and snapping rules every time. Language models choose sentences well and millisecond values badly, so the agent picks the words and reelcut does the arithmetic. As a consequence, word and utterance IDs must stay stable for a given transcript: re-transcribing a clip can renumber its words and invalidate an existing EDL. Explicit source times exist only in `drop_ranges`, for audio that has no word to point at.
